# 找免费 AI 工具，我现在会先打开 FindAIForMe

最近又多了一批能试的 AI 工具，收藏夹越来越乱。想找「视频翻译」「AI 检测」这类具体需求时，经常在各种列表里翻半天。

所以自己整理并上线了一个免费 / freemium AI 工具导航站：**FindAIForMe**（官网：https://findaifor.me/ ）。

## 首页一眼能看清什么

首页能看到约 **9,364** 个工具、**12** 个分类，支持中英切换，也可以提交你自己的工具。浅色目录页，搜索框直接写需求就行，比如「视频翻译 AI 工具」。
